# Vagonetki (Fabric 1.20.1)

Мод с вагонетками-транспортом и своими рельсами. Вкладка в творческом режиме: **Вагонетки**.

## Вагонетки и рельсы
| Вагонетка | Рельсы | Включение рельсов |
|---|---|---|
| Самолёт (крылья + винт) | чёрные | 1 блок редстоуна вплотную к рельсу, рельс светится жёлтым |
| Лодка | зелёные | 1 блок редстоуна |
| Слизь | любые рельсы | не нужно |
| Универсальная (самолёт + лодка + слизь) | синие | 2 блока редстоуна |

Вагонетку ставят на рельс как обычную. Сесть в неё (ПКМ), пока она стоит на **включённых** рельсах своего цвета: она «заводится» и дальше ездит/летит/плывёт сама, рельсы больше не нужны, пока вы не выйдете.

## Управление (на русской раскладке те же физические клавиши)
| Клавиша | Самолёт | Лодка | Слизь | Универсальная |
|---|---|---|---|---|
| W (Ц) | вперёд | вперёд | | вперёд |
| S (Ы) | вниз | назад | | вниз в полёте, назад на земле/воде |
| A (Ф) | влево | влево | | влево |
| D (В) | вправо | вправо | | вправо |
| Стрелка вверх | набор высоты | | | набор высоты |
| Пробел | | | прыжок | прыжок |

Стрелку вверх можно переназначить в настройках управления.
ЛКМ по вагонетке с блоком в руке ставит этот блок внутрь вагонетки (для вида). С пустой рукой или с Shift вагонетка ломается как обычно.

## Крафты
- Чёрный рельс (16): железо, чёрный краситель, палка, по схеме обычного рельса
- Зелёный рельс (16): то же с зелёным красителем
- Синий рельс (8): золото, синий краситель, палка, редстоун
- Вагонетка-самолёт: 2 пера, железный слиток, вагонетка
- Вагонетка-лодка: вагонетка + любая лодка (без порядка)
- Слизь-вагонетка: вагонетка + блок слизи (без порядка)
- Универсальная: самолёт + лодка + слизь (без порядка)

## Ресурспак Classic
Встроен в мод: Настройки, Ресурспаки, **Vagonetki Classic**. Перерисовывает текстуры самих вагонеток и рельсов в плоском «старом» стиле. Оригинальные текстуры Mojang в мод не включены.

## Сборка
Нужен JDK 17.

    ./gradlew build        # jar в build/libs/
    ./gradlew runClient    # тестовый запуск

В `.minecraft/mods` кладут jar вместе с Fabric API 0.92.2+1.20.1.

Текстуры и JSON-ресурсы генерирует `python3 tools/gen_assets.py` (нужен Pillow).
