# Vagonetki (Fabric 1.20.1)

Мод с вагонетками-транспортом и своими цветными рельсами. Вкладка в творческом режиме: **Вагонетки**. 10 вагонеток, 9 видов рельсов.

## Как это работает
1. Поставь вагонетку на рельс **своего цвета** (слизь-вагонетку можно на любой рельс).
2. Включи рельс: **один блок редстоуна вплотную к рельсу**. Рельс засветится жёлтым.
3. Сядь в вагонетку (ПКМ), пока она стоит на включённом рельсе. Она «заводится» и дальше едет, летит или плывёт сама, рельсы больше не нужны, пока не выйдешь.

## Вагонетки
| Вагонетка | Рельс | Что умеет |
|---|---|---|
| Самолёт | чёрный | летает, бочка (R), петля (G) |
| Лодка | зелёный | плавает по воде |
| Слизь | любой | прыжок с зарядом: зажми пробел, отпусти |
| Универсальная | синий | летает, плавает, прыгает, перевороты |
| Вертолёт | оранжевый | зависает в воздухе, ротор |
| Подлодка | бирюзовый | ныряет и плывёт под водой |
| Ледяная | ледяной | скользит с малым трением, лыжи, снежинки |
| Лавовая | лавовый | плывёт по лаве, огнестойкость пассажиру |
| Эндер | фиолетовый | пробел: телепорт вперёд до 7 блоков |
| Ракета | серебряный | быстрый полёт, разгон, огонь и дым |

## Управление (на русской раскладке те же физические клавиши)
| Клавиша | Действие |
|---|---|
| W (Ц) | вперёд |
| S (Ы) | назад / вниз |
| A (Ф), D (В) | влево, вправо |
| Стрелка вверх | набор высоты / всплытие (самолёт, вертолёт, подлодка, ракета, универсальная) |
| Пробел | прыжок (слизь, универсальная), телепорт (эндер) |
| R | бочка (самолёт, универсальная, в полёте на скорости) |
| G | петля (самолёт, универсальная, в полёте на скорости) |

Клавиши можно переназначить в настройках управления (категория «Вагонетки»).
ЛКМ по вагонетке с блоком в руке ставит этот блок внутрь вагонетки (для вида). С пустой рукой или с Shift вагонетка ломается как обычно.

## Крафты
Рельсы (железо I, краситель D, палка S: `IDI / ISI / I I`, получается 16 штук):
чёрный (чёрный краситель), зелёный, оранжевый, бирюзовый (голубой), ледяной (светло-синий), лавовый (красный), фиолетовый, серебряный (белый).
Синий рельс: золото `G`, синий краситель, палка, редстоун `GDG / GSG / GRG` (8 штук).

Вагонетки (везде нужна обычная вагонетка):
- Самолёт: 2 пера, железный слиток: `FIF / _M_`
- Лодка: вагонетка + любая лодка
- Слизь: вагонетка + блок слизи
- Универсальная: самолёт + лодка + слизь
- Вертолёт: 3 железных слитка сверху, вагонетка снизу по центру
- Подлодка: вагонетка + 2 призмариновых осколка + стекло
- Ледяная: вагонетка + синий лёд
- Лавовая: вагонетка + магмовый блок + огненный порошок
- Эндер: вагонетка + глаз Эндера
- Ракета: вагонетка + 2 фейерверка + порох

## Эффекты и звуки
Облака от крыльев самолёта и искры при перевороте, брызги и плеск у лодки, пузырьки у подлодки, снежинки у ледяной, лава и огонь у лавовой, портальные частицы у эндера, пламя и дым у ракеты, слизь при прыжке и приземлении. Звуки негромкие, привязаны к движению.

## Ресурспак Classic
Встроен в мод: Настройки, Ресурспаки, **Vagonetki Classic**. Перерисовывает текстуры вагонеток и рельсов в плоском стиле. Оригинальные текстуры Mojang в мод не включены.

## Сборка
Нужен JDK 17.

    gradle build         # Gradle 8.8+, jar в build/libs/
    gradle runClient     # тестовый запуск

В `.minecraft/mods` кладут jar вместе с Fabric API 0.92.2+1.20.1.
Текстуры и JSON-ресурсы генерирует `python3 tools/gen_assets.py` (нужен Pillow).

## CI
Готовый workflow лежит в `ci/build.yml`. Чтобы GitHub собирал jar при каждом пуше, перенеси его в `.github/workflows/build.yml`.
